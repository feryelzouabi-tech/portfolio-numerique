Chapitre 2 : Prompt Engineering

Le Prompt Engineering (ou l'art de concevoir des consignes pour l'intelligence artificielle) permet d'obtenir des résultats précis, structurés et exploitables en minimisant les erreurs (hallucinations).

La structure idéale d'un prompt performant :

  • Rôle (Persona) : Indiquer à l'IA qui elle doit incarner (ex: "Agis en tant qu'expert en cybersécurité...").
  • Contexte : Fournir les arrière-plans et la situation (ex: "...pour une présentation devant des étudiants en informatique.").
  • Tâche : Préciser exactement ce que l'IA doit faire.
  • Format : Définir la structure de la réponse attendue (tableau, puces, code Markdown, etc.).

🔍 3 Cas Pratiques : Avant / Après

Cas 1 : Explication de code

❌ Avant (Prompt faible)

"Explique-moi ce code C."

✅ Après (Prompt structuré)

"Agis en tant que tuteur en programmation C. Explique-moi la fonction des pointeurs dans ce code en 3 points simples avec des analogies."

Cas 2 : Rédaction d'un e-mail administratif

❌ Avant (Prompt faible)

"Ecris un mail pour demander un stage."

✅ Après (Prompt structuré)

"Rédige un e-mail professionnel en français destiné à un responsable RH pour demander un stage de fin de 1ère année en TI. Ton poli, concis, mettant en avant mes compétences en Python et Web."

Cas 3 : Résumé de cours

❌ Avant (Prompt faible)

"Résume ce cours de réseaux."

✅ Après (Prompt structuré)

"Agis en tant qu'expert pédagogique. Résume ce cours sur le modèle OSI en extrayant uniquement les 4 couches principales sous forme de tableau comparatif."

📚 Bibliothèque de Prompts Utiles

1. Correcteur de bugs de code 
Agis en tant qu'expert en développement. Analyse ce code [insérer le langage], identifie les erreurs de syntaxe ou de logique, explique la cause et donne la version corrigée.
2. Générateur de Quiz de révision 
Agis en tant qu'examinateur universitaire. À partir de ce résumé de cours, génère 3 questions à choix multiples (QCM) avec correction détaillée.
3. Traducteur technique simplifié 
Prends ce texte technique complexe en anglais et traduis-le en français en l'expliquant avec des termes simples adaptés à un étudiant de 1ère année.
