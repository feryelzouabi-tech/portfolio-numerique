Projet 1 : Calculateur de Moyenne Semestrielle

Un script simple permettant de calculer la moyenne générale d'un étudiant en TI à partir des notes de TP et de contrôles.

def calculer_moyenne():
    print("--- Calculateur de Moyenne ISETN ---")
    note_tp = float(input("Entrez la note de TP : "))
    note_ds = float(input("Entrez la note de DS : "))
    note_exam = float(input("Entrez la note d'Examen : "))
    
    moyenne = (note_tp * 0.2) + (note_ds * 0.3) + (note_exam * 0.5)
    print(f"Votre moyenne pondérée est : {moyenne:.2f} / 20")

calculer_moyenne()

Projet 2 : Jeu du Nombre Mystère (Boucles & Conditions)

Un jeu interactif où l'utilisateur doit deviner un nombre aléatoire généré par le programme.

import random

def deviner_nombre():
    secret = random.randint(1, 20)
    essai = 0
    print("Devinez le nombre entre 1 et 20 !")
    
    while True:
        choix = int(input("Votre proposition : "))
        essai += 1
        if choix < secret:
            print("C'est plus haut ! 📈")
        elif choix > secret:
            print("C'est plus bas ! 📉")
        else:
            print(f"Bravo ! Trouvé en {essai} essais. 🎯")
            break

deviner_nombre()

Projet 3 : Gestionnaire de Liste de Tâches (To-Do List)

tâches = []

def afficher_taches():
