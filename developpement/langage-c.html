Module : Programmation en Langage C

Le langage C est la base de la programmation procédurale et de l'architecture logicielle. Ce module présente les structures de contrôle, la manipulation des tableaux et l'utilisation des fonctions à travers des programmes testés sous GCC.

⚙️ 3 Programmes Fondamentaux

1. Affichage et Conditions (Gestion des notes)

#include <stdio.h>

int main() {
    float moyenne;
    printf("Entrez votre moyenne générale : ");
    scanf("%f", &moyenne);

    if (moyenne >= 10.0) {
        printf("Admis(e) ! Excellent travail.\n");
    } else {
        printf("Ajustement nécessaire au prochain semestre.\n");
    }
    return 0;
}

2. Tableaux et Boucles (Calcul de la valeur maximale)

#include <stdio.h>

int main() {
    int notes[5] = {12, 15, 9, 18, 14};
    int max = notes[0];

    for(int i = 1; i < 5; i++) {
        if(notes[i] > max) {
            max = notes[i];
        }
    }
    printf("La note maximale est : %d\n", max);
    return 0;
}

3. Utilisation des Fonctions (Calcul du carré)

#include <stdio.h>

int carre(int nombre) {
    return nombre * nombre;
}

int main() {
    int x = 6;
    printf("Le carré de %d est %d\n", x, carre(x));
    return 0;
}
